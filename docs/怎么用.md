# dsh-wb-import — 怎么用

## 界面在哪

**设置 → 插件 → 「WorkBuddy 导入」**

这是一个独立的设置页（tab），不需要在对话里跟 AI 说话。

## 操作步骤

1. 打开 **设置 → 插件**，找到「WorkBuddy 导入」页
2. 用筛选框找到要导入的会话，**勾选**（表头复选框可全选当前筛出的）
3. 在下方填**目标工作区目录**（绝对路径，比如 `D:\Users\SongDing\DSH\零星工作`）
4. 点 **导入选中的会话**
5. 结果会逐个显示：✓ 成功（带事件数）/ ✗ 失败（带原因）
6. **重启 DSH** 后，导入的会话出现在对应工作区的侧边栏

## 回滚

导入过的会话会记在台账里（页面底部那块）。

- 勾选要撤销的项 → 点 **回滚选中**
- 会弹确认框，确认后删除对应的会话目录
- 只删插件自己导入的 `session-wb-*` 会话，**绝不碰原生会话**

## 也可以让 AI 帮你做

同样的能力也注册成了模型工具，你在对话里直接说就行：

- 「列出 workbuddy 的会话」→ 调 `wb_list_sessions`
- 「把 xxx 导入到 yyy」→ 调 `wb_import_session`（需要你明确说出 id 和目录）
- 「回滚刚才那次导入」→ 调 `wb_rollback_import`

工具的 description 里写明了「不得擅自调用」，必须你明确要求。

## 技术细节

### 路由（host 半区）

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/dsh-wb-import/sessions` | 列出 WorkBuddy 会话 |
| GET | `/dsh-wb-import/ledger` | 读导入台账 |
| POST | `/dsh-wb-import/import` | 导入 `{ sessionIds, workspaceDir }` |
| POST | `/dsh-wb-import/rollback` | 回滚 `{ ids?, all?, confirm }` |

### 安全边界

- **导入不直接写文件**：走宿主 `sessionPersistence` 服务（create → append → flush → close），
  由 DSH 自己负责目录布局、zstd 编码、格式校验、索引更新
- **workspaceDir 必须绝对路径、不含 `..`**，拿不到就拒绝，不做静默兜底
- **回滚 5 道护栏**：只认 `session-wb-` 前缀 → cwd 绝对 → 拒绝 `..` → 工作区编码合理 → 父目录匹配
- **台账损坏时拒绝操作**，不静默清空

## 已知限制

1. 导入的会话可续聊也可写（DSH 没有只读会话概念）
2. 用非原模型续聊时 thinking 会被当正文重放（DSH 自身行为）
3. 不搬文件历史/附件
4. 回滚只删目录，索引要重启后才更新
5. 导入前不会自动备份整个 `~/.dsh`（台账只记录导了什么）

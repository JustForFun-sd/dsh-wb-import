# 重启 DSH 后怎么验证插件

## 根因（这次查清了）

DSH 主进程是 **15:06 启动的，之后一直没退**。
我 15:47 改的配置它根本没读到 —— 之前几次"重启"只是新窗口/新会话，主进程没退。

**必须彻底退出 DSH 进程再重开。**

## 重启步骤

1. **关闭 DSH 主窗口**
2. **右键托盘图标 → 退出**（关键，光关窗口进程还在）
3. 确认任务管理器里没有 `DeepSeek Harness.exe`
4. 重新打开 DSH

## 重启后验证

打开 **设置 → 内置插件**，应该能看到多一个 tab：「WorkBuddy 导入」。

如果还是没有，按一次**插件刷新按钮**（`unlag-reload.log` 说前端插件是手动刷新加载的）。
